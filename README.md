随着产品系列持续扩展，本仓库将逐步收录不同类型产品的技术资料，并通过统一的目录和文档入口进行管理。

## 2. 技术资料分类

本仓库主要提供产品使用和开发相关的技术资料，包括：

- **使用说明与快速入门**：设备使用、安装、配置及基本操作。
- **配置与集成教程**：设备参数配置、系统集成及应用示例。
- **开发资料**：SDK、API、通信协议、示例代码及开发指南。
- **常见问题（FAQ）**：使用过程中常见问题及排查方法。
- **版本与更新记录**：技术文档、示例程序及相关资料的更新说明。

产品选项、规格书、认证与测试报告等正式产品资料，请通过对应产品页面中的链接查看。

## 3. 如何查找资料

建议按照以下方式查找所需内容：

1. **查找产品信息**：先进入对应产品系列，选择具体型号。
2. **了解产品规格**：通过型号页面访问官网产品介绍及规格书。
3. **学习使用方法**：查看该型号对应的使用说明、配置教程和常见问题。
4. **进行开发集成**：进入开发资料目录，查找适用的 SDK、API、协议或示例代码。
5. **查找认证及测试资料**：通过型号页面中的相关链接访问正式资料。

如果多个型号共用同一份教程或开发资料，仓库将集中维护该文档，并在适用型号的页面中提供链接，以减少重复内容并便于后续更新。

## 4. 产品型号与文档适用范围

不同型号或不同硬件、固件版本之间可能存在功能、接口、配置方式或操作流程上的差异。

使用文档或示例代码前，请确认：

- 文档中列出的适用产品型号；
- 设备的硬件版本及固件版本；
- 文档中的接口、参数和操作步骤是否适用于当前设备。

如文档明确列出适用型号或版本，请以该范围为准。
