
# ConkMile 信标及物联网产品技术资料

欢迎访问 ConkMile 技术资料仓库。

本仓库用于整理和维护 ConkMile 信标及相关物联网产品的技术文档，帮助用户、开发者和合作伙伴快速查找产品资料、了解产品使用方法，并完成设备配置、开发集成与问题排查。

随着产品系列持续扩展，本仓库将逐步收录不同类型产品的技术资料，并通过统一的目录和文档入口进行管理。

## 2. 技术资料分类

本仓库主要提供产品使用和开发相关的技术资料，包括：

- **使用说明与快速入门**：设备使用、安装、配置及基本操作。
- **开发资料与配置教程**：SDK、API、通信协议、示例代码及开发指南、设备参数配置、系统集成及应用示例。
- **认证与测试报告**：CE、FCC、KC、ROHS、IP68.
- **常见问题（FAQ）**：使用过程中常见问题及排查方法。

产品选项、规格书、认证与测试报告等正式产品资料，请通过对应产品页面中的链接查看。
