## 如何查找资料

1. 在上方产品型号表中选择对应型号。
2. 进入该型号的技术文档页面，确认文档适用的型号及版本。
3. 根据需要查看使用说明、配置教程、开发资料或常见问题。
4. 如需产品规格、认证或测试报告，请通过型号页面中的官方资料链接查看。

如果多个型号适用同一份文档，将集中维护该文档，并从各型号页面提供入口。若型号之间存在操作、接口或配置差异，将在对应型号的文档中单独说明。

## 文档适用范围

不同型号或不同硬件、固件版本之间可能存在功能、接口或配置方式上的差异。使用文档或示例代码前，请确认其适用的产品型号及版本。

如文档明确列出适用型号或版本，请以文档标注的范围为准。
